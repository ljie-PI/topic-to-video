# Style Hint — Frag Note × 安静明亮的编辑风

> 默认主题，改编自 Frag Note Design System。适合未指定主题的讲解视频：暖白画布、克制的薰衣草强调、清晰的信息层级与低干扰的编辑感。

## 配色（只用以下颜色）

```css
--canvas:              #FAF9F5; /* 主背景 / 留白 */
--surface-soft:        #F6F3EE; /* 分组底色 */
--surface-card:        #F0ECE6; /* 低强调卡片 */
--surface-raised:      #FFFEFB; /* 内容卡 / 输入区 */
--text:                #1F1D24; /* 标题 / 主文字 */
--body:                #4D4954; /* 正文 */
--muted:               #716C79; /* 辅助信息 */
--line:                #E3DED8; /* 分隔线 / 低强调边框 */
--line-strong:         #D4CEC7; /* 较强边界 */
--accent:              #6F5BD3; /* 唯一品牌强调 */
--accent-ink:          #49399B; /* 浅紫底上的文字 / 图标 */
--accent-soft:         #EEEAFE; /* 标签 / 选中态 / 弱强调 */
--success:             #397352;
--warning:             #916019;
--error:               #AD414A;
```

### 主题专属标记

- 以暖白 `--canvas` 为主背景，浅紫 `--accent` 只用于关键数字、当前步骤、链接、短标签或单一重点。
- 文字层级使用 `--text`、`--body`、`--muted`；不要把浅紫当大段正文颜色。
- 状态色仅表达真实的成功、注意或风险，不能作为装饰配色。

### 颜色使用场景

- 内容卡优先 `--surface-raised + --line`；同一信息组优先靠间距和浅底分区，不要堆叠卡片。
- 可选用 `--surface-soft` / `--surface-card` 做柔和 band、表格行或信息分组；不使用渐变。
- 深色 `#211F26` 仅可用于短暂的代码、终端或媒体局部，不做整段 scene 背景。

### 标题配色与高亮 box

- 标题和主数字使用 `--text`；单个关键词或数字可用 `--accent`。
- 高亮使用 `--accent-soft` 作为紧贴文字的短标签或小型 callout，不做大面积紫色底板。

### `visual_role` 色彩覆盖

- `big_number` / 关键节点：`--accent` 或 `--accent-soft + --accent-ink`。
- `data_table` / `chart`：主系列只用 `--accent`；辅助系列用暖灰，状态系列才使用 success / warning / error。
- `list` / `timeline` / `process_flow`：默认暖灰线条，当前项用 `--accent`。

### 对比度 guardrails

- 正文、字幕和关键信息必须保持在实色背景上可读；浅紫底只配 `--accent-ink` 或 `--text`。
- 不用低对比浅灰文字表达主信息，不用半透明文字代替层级。

## 排版

- 使用 Phase 7 预置的本地 `NotoSansSC` 作为中文与通用正文；`IBMPlexMono` 仅用于数字、来源、代码或短数据标签。
- 标题使用 600 字重，正文使用 400/500；避免 700+ 的粗重风格。
- 标题、按钮、标签使用自然句式，不把全大写或高 tracking 小字作为常规装饰。
- 排版干净、宽松、轻编辑感；正文和字幕保持足够行高，不模拟纸张手写体。

## 视频尺寸（覆盖网页常规尺寸）

- 仍以 `references/composition-rules.md` 的字体下限、字幕安全区、内容区和 layout routing 为准。
- 横屏可使用清晰的宽幅素材 + 简短信息 rail；竖屏优先上下分区、纵向列表和单一视觉重点。
- 保留有意且对称的暖白留白，但不得违反 R14 的内容覆盖与空白限制。

## 形状风格

- 控件 / 小标签圆角 8px，常规信息卡 12px，hero 或大信息容器最多 16px；不要混用随意的圆角值。
- 使用 1px `--line` 或极轻阴影区分层级；默认不悬浮、不玻璃化、不做厚重投影。
- 卡片应服务于信息分组；已有清楚层次时，用间距和细分隔线替代额外卡片。

## 图标

- 使用简洁的线性图标，颜色跟随 `--body` 或 `--accent-ink`；尺寸与文字基线对齐。
- 不使用 3D emoji、拟物贴纸、彩色 icon 拼盘或装饰性 logo 墙。

## 动效

- 运动强度低而有目的：文本和信息单元按旁白逐步出现，素材保持克制的内容驱动运动。
- 进入 / 退出以 opacity 与 transform 为主，短促、平稳；不要让背景、渐变、粒子或无意义装饰持续运动。
- 交互式 hover / pressed 规则不直接移植为视频动效；视频时序仍服从 R18、R19 与旁白节奏。

## 不要做

- 不要使用渐变、glassmorphism、发光球、neon halo、厚投影或大面积紫色。
- 不要把每一段文字都装进卡片，也不要把卡片当作填满画面的手段。
- 不要用手写字体、复古纸张纹理、终端 / manpage 外观或新闻播报包装，除非用户明确指定其他主题。
- 不要为了“安静”而缩小正文、降低对比度、延迟信息出现或让 scene 长时间无内容变化。
