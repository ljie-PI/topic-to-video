# Pattern：continuation（同一素材连续讲解）

相邻几个 scene 围绕同一张图 / 同一个 clip 连续讲解：主素材保持稳定，只刷新解释层和局部强调。本文件是建议，不是规则。

## 适用场景和触发信号

- 相邻段落都在讲同一素材（论文 figure、技术架构图、UI 截图、流程图），需要围绕它讲多个点。
- 场景规划里相邻 scene 标注 `layout_role = "media_continuation"` 和同一 continuation group。
- 按句子节奏、局部强调或屏幕文本密度把一段长讲解拆成多个 scene 时，用本 pattern 保持视觉锚点；能合并成一个 scene 时合并更省事。

## 区域尺寸建议

- 主素材的位置、尺寸、裁切窗口在相邻 scene 间保持一致；只有解释层变化。
- 解释层（文本、callout、局部高亮）的尺寸按内容区剩余空间规划，避免为了塞解释而移动主素材。

## 横屏摆法

- 主素材固定，解释文本外置或分时刷新；每个 scene 只讲新的一个点。
- 局部强调（重点区域高亮、marker）随旁白逐个出现和消失。

## 竖屏摆法

- 与横屏相同：主素材不动，解释层在下方或上方纵向刷新。
- 信息过密时优先拆 scene 或降级次要信息，不动主素材的版面位置。

## 动效候选与应避免

候选：主素材保持不动；解释层刷新（局部 emphasis、重点区域高亮、文本替换）；需要时使用 rack focus 在层级间转移焦点。

避免：主媒体在 scene 边界 full-scene fade、wipe、slide-out 后重新入场；解释层动画带动主素材一起动；图片长时间消失后再出现。

## 用色

- 外观全部来自所选主题的 token；本 scene 的焦点色随「当前正在讲的点」移动，与 `motion.md` 的「一个 scene 一个主打机制」配合。
- 本 pattern 没有按 visual_role 的特殊覆盖；局部高亮用 `--c-focus` / `--c-focus-tint` 或真实状态色。
