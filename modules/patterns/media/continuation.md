# Pattern：continuation（同一张技术图深入连续讲解）

围绕**同一张技术图**做深入拆解，且按解释层次拆成相邻连续的多个视觉 scene 时：相邻切点之间**不加打断性过场**，并**优先 zoom in 到图片当前讲解的不同局部区域**，用连贯的镜头推进保持空间锚点。这是真实素材跨多个视觉 scene 使用的唯一适用形态；能合并延长为一个更长的视觉 scene 在内部逐步推进时，优先合并为一个 scene。本文件是建议，不是规则。

## 适用场景和触发信号

- 同一张信息密度高的技术图（论文架构图、算法流程图、复杂实验对比图、系统拓扑图）需要依次深入讲解多个模块、步骤或数据区域，单次定格讲不透。
- 因字幕预算、版面分区或局部特写切换需要拆成**相邻连续**的多个视觉 scene（非连续、隔着其他话题的场景不得复用同一素材；普通配图或通用 B-roll 不套用本 pattern 跨场景复用）。
- 能合并延长为单个视觉 scene 并在内部做分步镜头推拉时，优先用单个长 scene 承载整段连续配音，比拆成多个 scene 更紧凑。

## 区域尺寸建议

- 主图视口在相邻连续 scene 间保持同一容器基准（避免无理由跳变外框位置），视口内部按讲解重点做局部放大（zoom in）与平移，确保当前所讲模块 / 数据点清晰可读且不切碎必要的上下文（如坐标轴、关键连接边）。
- 外置解释区（文本、callout）按内容区剩余空间规划，各 scene 只放当前局部区域的解释，不堆叠已讲完的冗余文字。

## 横屏摆法

- 首段可先给总览建立空间关系（或直接切入首个模块区域），后续相邻 scene 无过场衔接，镜头平滑 zoom in / pan 到当前讲解的局部模块，右侧或下方外置信息同步刷新当前重点。
- 局部强调（重点区域框选、箭头、marker）随镜头焦点逐段转移，讲完即降级或收起。

## 竖屏摆法

- 上部或中上部保持统一的图片视口，相邻 scene 无过场切换到不同局部 zoom 区域，下方解释层按段纵向刷新。
- 竖屏横向宽度有限时，局部 zoom 比整张宽图缩成窄条更易看清图中文字与连线。

## 动效候选与应避免

候选：切点无过场直连 + 跨相邻 scene 延续的局部 zoom in / pan（总览 → 局部 A → 局部 B，必要时回到全局收束）；局部高亮框、connector 生长、外置解释层轻量替换、rack focus。

避免：相邻连续 scene 之间插入 `tile-wipe`、整屏 fade / wipe / slide-out 后把同一张图重新入场；连续多个 scene 里整张图位置与缩放完全不动、只换外置说明文字；把已用过的图片隔几个场景又拿出来充当新画面。

## 用色

- 外观全部来自所选主题的 token；本 scene 的焦点色可随「当前正在讲的点」移动。
- 本 pattern 没有按 visual_role 的特殊覆盖；局部高亮用 `--c-focus` / `--c-focus-tint` 或真实状态色。
