# Pattern：band（横带）

一个超宽 / 长条形素材以一条足够高的信息横带成为 scene 主体。本文件是建议，不是规则。

## 适用场景和触发信号

- 单个 ultra-wide / strip 素材（时间线、全景图、横幅截图），在内容区内能形成一条足够高的可读信息带。
- 完整展示后高度仍可读；如果只能变成一条细线，就不适合本 pattern，改看 `patterns/media/viewport-reveal.md`、分时或拆 scene。
- 场景规划里 `layout_role = "band"`。

## 区域尺寸建议

- 带高建议不低于内容区高度的 1/4（例如 stage 布局主展示区 764px 高时，带高约 190px 以上），且带内文字、刻度、标签清晰可读。
- 带的宽度通常撑满内容区宽度；上下留外置信息区放结论或 callout。
- 竖屏只在带高能保住可读性时使用，否则改用 reveal / 分时 / 拆 scene。

## 横屏摆法

- 超宽素材上下居中或偏中放置成一条带，上下配短结论、刻度说明或重点 callout。
- 带很长时沿长轴 reveal 或 scrub，配合旁白逐段点亮。

## 竖屏摆法

- 超宽素材在竖屏里容易退化成细线：优先横向 reveal、分时展示或拆 scene。
- 若内容允许，只截取最关键的一段作为中上部 band，其余部分交给相邻 scene。

## 动效候选与应避免

候选：沿长轴 reveal、scrub、highlight stepping（按旁白逐段点亮带上的区域）。

避免：3D 倾斜或过小缩放降低带的可读性；把不可读的细条当作 band 使用。

## 用色

- 外观全部来自所选主题的 token；带的边框用 `--c-border`，重点段 marker 可用 `--c-focus` 或真实状态色。
- 本 pattern 没有按 visual_role 的特殊覆盖。
