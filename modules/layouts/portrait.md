# 布局：竖屏模式（portrait）

竖屏通用布局，不属于任何一类视频。**没有主持人和顶部导航栏**，整条竖幅从上到下是页眉、主内容、字幕三个纵向分区。

**所有区域的位置和尺寸都是固定的**。模板和组件只往区域里填内容，不移动、不缩放区域本身。内容放不下时，在区域内部缩小、滚动或分页。

画布有两种变体：**1080×1920（9:16）** 和 **1080×1440（3:4）**。本文档同时写两个变体的区域表；区域定义是一份画布一个 JSON（机器可读格式只装得下一张画布）：`portrait.json` 是 1080×1920，`portrait-3x4.json` 是 1080×1440。**JSON 里的数值必须和本文档的区域表一致**，改任何一个都要同步另一个。

竖屏字幕允许两行。字幕规格（文字区宽度、字号、最大行数）由所选 layout 的区域定义决定，不由主题决定；主题只供字体和颜色。分段宽度取 `caption.width_px`，默认 42px——`python3 scripts/align-narration.py --layout modules/layouts/portrait.json` 直接读这份规格。

     │  │                          │  │
     │  │                          │  │
     │  │   主展示区               │  │
     │  │   70, 300 · 940 × 1240   │  │
     │  │                          │  │

     │                                │

     │  70, 1620 · 940 × 200          │

| 区域 | 位置（左, 上） | 尺寸（宽×高） | 放什么 | 由谁填 |
|---|---|---|---|---|
| 背景 | 0, 0 | 1080×1920 | 主题背景（`--ground`），静态 | 视频的 `index.html`（`--ground`） |
| 页眉 | 70, 120 | 940×140 | 标题、日期或当前项目的一句话身份 | 模板 |
| 主展示区 | 70, 300 | 940×1240 | 全部主要内容：纵向榜单、行卡、媒体 slab、图表 | 模板 |
| 字幕文字区 | 70, 1620 | 940×200 | 居中字幕，最多两行 | 组件 `caption-bar`（或无条字幕遮罩） |

## 层级（z-index）

| 层 | z-index | 内容 |
|---|---|---|
| 背景 | — | `#ground`，在根节点最底层 |
| 场景 | 2 | 模板里的场景，按时间先后排在同一轨 |
| 转场 | 10 | 组件 `transitions/tile-wipe` |
| 字幕 | 16 | 组件 `caption-bar` |

## 竖屏摆法与信息密度

竖屏的内容区是窄列，先扣除底部字幕区再规划；多元素 / 结构型内容不得沿用横屏的左右窄栏、多列硬排。

- 优先纵向叙事和分时轮换：纵向榜单、分页 Top N、一次突出一个条目；避免左右窄栏。
- 分区的默认形状是上下堆叠（页眉 / 主内容 / 字幕），不要直接套横屏的右侧栏。
- 流程、时间线、状态机用纵向节点链；禁止 3 个以上横向窄节点。
- 架构图 / 网络图用模块层级、focus window 或 primary path，避免 dense full graph。
- 指标 / 数据块最多 2 列；list / grid 用纵向卡片或最多 2 列，每项短 label + 一行 detail。
- 横宽视频 / 图片放上半屏或中上部的清晰 slab；极端比例素材宽度驱动 reveal，沿长轴覆盖重点。
- 信息过密时优先轮换、分页、降级次要信息或拆场景；**不得**缩字号、缩素材或侵入字幕文字区。遇到文本框过窄、label 多次换行或节点 / 行 / 卡片不可读时，按上面的形态降级，仍不可读就拆场景。

## 不要做

- 不要把主展示区内容画出区域外，尤其不要压到字幕文字区。
- 字幕不要超过 `caption.width_px` 对应的显示宽度，不要超过两行。
- 不要在竖屏左侧或右侧塞横屏式 side rail。
