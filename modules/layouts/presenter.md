# 布局：讲解模式（presenter）

这是带主持人的通用横屏布局，用不用模板都可以选它。一个人物坐在页面右下角讲解，左侧大区域展示主要内容，人物上方的区域放辅助信息。顶部是导航栏，底部是字幕条，上下对称。

**所有区域的位置和尺寸都是固定的**。模板和组件只往区域里填内容，不移动、不缩放区域本身。内容放不下时，在区域内部缩小或滚动。

画布 1920×1080，30 fps，左右边距都是 96px（画面宽度的 5%，正好在 90% 动作安全框的边线上）。

机器可读的区域定义在同目录的 `presenter.json`（`canvas` / `regions` / `caption` 三段，reserved 区域带 `component`）。**JSON 里的数值必须和本文档的区域表一致**，改任何一个都要同步另一个。字幕分段脚本（`align-narration.py --layout`）直接读 `caption` 段。

## 区域

| 区域 | 位置（左, 上） | 尺寸（宽×高） | 放什么 | 由谁填 |
|---|---|---|---|---|
| 背景 | 0, 0 | 1920×1080 | 主题背景（纸纹），静态 | 视频的 `index.html`（`--ground`） |
| 导航栏 | 0, 0 | 1920×72 | 站点标志、页面路径、章节标签页；当前章节下有下划线，充当整片的进度条 | 组件 `nav-bar` |
| 页眉行 | 96, 100 | 1048×72 | 页面标题加日期，或当前项目的标题条（排名、路径、star） | 模板 |
| 主展示区 | 96, 196 | 1048×788 | 最重要的画面：README 截图、产品演示视频、项目封面的大标题区 | 模板 |
| 副展示区 | 1184, 100 | 640×522 | 辅助信息：榜单（最多 5 行）、功能步骤、logo 卡片 | 模板 |
| 人物区 | 1294, 642 | 420×420 | 人物动作组件。水平居中对齐副展示区（中心 x = 1504），笔记本底边压在字幕条上约 20px | 组件 `jay` |
| 字幕条 | 0, 1008 | 1920×72 | 深色条，和导航栏对称 | 组件 `caption-bar` |
| 字幕文字区 | 96, 1008 | 1166×72 | 单行字幕，左对齐，垂直居中；右边界停在人物左边缘前 32px（x = 1262） | 组件 `caption-bar` |

各区域之间的间距：
- 主展示区和副展示区之间 40px（1144 → 1184）；
- 页眉行底到主展示区 24px；
- 主展示区底到字幕条 24px；
- 副展示区底到人物头顶约 30px。

## 层级（z-index）

| 层 | z-index | 内容 |
|---|---|---|
| 背景 | — | `#ground`，在根节点最底层 |
| 场景 | 2 | 模板里的场景（每个场景一个挂载点，按时间先后排在同一轨） |
| 转场 | 10 | 组件 `transitions/tile-wipe`，盖住场景，从导航栏和字幕条下面穿过 |
| 导航栏 | 15 | 组件 `nav-bar` |
| 字幕 | 16 | 组件 `caption-bar` |
| 人物 | 20 | 组件 `jay`，永远在最上面 |

## 挂载规则

- **常驻组件**（导航栏、字幕条、转场、人物）各挂一次，`data-start="0"`，时长等于整支视频。它们的数据用的是视频时间（秒）。
- **场景模板**按时间顺序挂在同一轨，`data-start` 是场景开始的时间，模板内部的时间从 0 算起。
- 场景之间用方格转场 `tile-wipe` 衔接：转场的切点时间等于下一个场景的 `data-start`。新场景的内容要在切点后 0.55 秒（方格退去时）才开始出现，开头这段被方格盖着。

## 人物和区域的配合

人物会看向正在讲的区域。在人物的动作剧本里：
- 讲到副展示区里的东西（比如榜单某一行）时，加一次 `U`（向上看），时长 1 秒左右；
- 讲到主展示区里的东西时，加一次 `L`（向左看）。

人物缩放后，思考气泡和“!”也会一起变小。在 420px 时建议把人物组件的 `fxScale` 设为 1–1.35，保证气泡里的字读得清。

## 不要做

- 不要把主展示区或副展示区的内容画到区域外面，尤其不要压到人物区和字幕条上。
- 不要在人物区上方放会被人物挡住的文字。副展示区的底边是 622，人物头顶在 652 左右，中间只留了 30px。
- 字幕不要超过 1166px 宽，不要折成两行。
