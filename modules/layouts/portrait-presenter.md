# 布局：竖屏讲解模式（portrait-presenter）

通用带主持人竖屏布局：顶部 88px 深色导航栏，往下是全宽页眉与主展示区，主展示区下方左侧是副展示区、右侧坐主持人，底部为全宽深色双行字幕条。

**所有区域的位置和尺寸都是固定的**。模板和组件只往区域里填内容，不移动、不缩放区域本身。内容放不下时，在区域内部 zoom-in、滚动或分页。

含两种画布变体：**1080×1920（9:16）** → `portrait-presenter.json`，**1080×1440（3:4）** → `portrait-3x4-presenter.json`（数值与本文区域表严格一致）。

各区域间距（两种竖屏画布通用）：
- 导航栏下沿到页眉 32px（9:16）/ 2px（3:4）；
- 页眉底到主展示区 40px；
- 主展示区底到副展示区 40px；
- 副展示区底到字幕条 24px；
- 副展示区右缘到人物区左缘 40px，人物区右缘距画布右边界 60px，人物区底边与字幕条上沿对齐。

## 层级（z-index）

| 层 | z-index | 内容 |
|---|---|---|
| 背景 | — | `#ground`，在根节点最底层 |
| 场景 | 2 | 各视觉场景挂载点，按时间先后排在同一轨 |
| 转场 | 10 | 转场 `tile-wipe`（`transitions/tile-wipe/`），盖住场景，从导航栏、字幕条和人物下面穿过 |
| 导航栏 | 15 | 组件 `nav-bar`，盖住画面上沿 |
| 字幕 | 16 | 组件 `caption-bar` |
| 人物 | 20 | 组件 `presenter`，永远在最上面 |

## 挂载规则

- **常驻组件**（导航栏、字幕条、人物）各挂一次，`data-start="0"`，时长等于整支视频，宿主 `data-width` / `data-height` 对应全片竖屏画布（`1080×1920` 或 `1080×1440`）；采用转场时，常驻转场挂一次，`data-start="0"`，时长等于整支视频。它们的数据用的是视频时间（秒）。
- 导航栏传 `{"mode": "compact", "logo": "assets/brand/…", "path": "…"}`（`z-index: 15`，见 [nav-bar 文档](../components/nav-bar/nav-bar.md)）；`nav-bar` 无按 scene 显隐能力，混用无导航栏的 `portrait` 场景时不要挂 `nav-bar`。
- 同片混用无主持人竖屏场景（`portrait` / `portrait-3x4`）时，不重挂组件，也不要给 `caption-bar` 传 `bar: "off"`：通过 `VIDEO.presenter.placements` 切换人物显隐与几何，通过 `VIDEO.captionSegments`（含 `caption_bar_rect`）自动切换底部字幕条显隐与双行文字区宽度。
- 采用方格转场 `tile-wipe` 时，按 [tile-wipe 文档](../transitions/tile-wipe/tile-wipe.md) 传入本布局边界与笔记本起点：`9:16` 为 `{"originX": 870, "originY": 1709, "top": 88, "bottom": 1776}`，`3:4` 为 `{"originX": 890, "originY": 1238, "top": 88, "bottom": 1296}`；竖屏 1080px 宽度下默认省略转场预告卡片（只做纯方格过渡）。

## 人物和竖屏区域的配合

主展示区在人物上方，副展示区在人物左侧：讲主展示区瞥视 `U`，讲副展示区瞥视 `L`，人物 `size` 为 `300`（9:16，配 `fxScale: 1.4`）/ `260`（3:4，配 `fxScale: 1.6`）；详见 [presenter 组件文档](../components/presenter/presenter.md)。

## 副展示区

- **默认只排页眉 + 主展示区（`header` + `main`），一般不放 `side`**：单个动态图示、流程拓扑或焦点素材在主展示区内已完整表达时，副展示区保持留白。
- **启用 `side` 的条件与跨区互补原则**：仅当存在独立的大块文本 / 榜单 / 指标组，或只放 `header` + `main` 明显空旷时启用；`side` 内容须与 `main`、`header` 互补，不得重复 `main` 的文案。

## 元素尺度（按 [`designs.md`](../designs/designs.md) 代入）

| 元素 | 主展示区 940×900 / 940×630 | 副展示区 610×512 / 650×352 |
|---|---|---|
| 指标数字（配说明同框） | ≤ 88（说明 ≥ 36px）/ ≤ 72（≥ 30px） | ≤ 60（≥ 26px）/ ≤ 42（≥ 22px） |
| 封面核心数字（整片一次） | ≤ 104（配 ≥ 42px）/ ≤ 84（≥ 34px） | 不放 |
| 区域主图标 / logo | ≤ 160 | ≤ 154 / ≤ 106 |
| 行内图标 | 行字号 × 0.8–0.9 | 同左 |

## 竖屏摆法与信息密度

内容组织遵循 [portrait.md](portrait.md) 的「竖屏摆法与信息密度」：主展示区保持 940px 全宽上下堆叠与分时轮换，不塞左右窄栏；纵向条目数按主展示区高度（900px / 630px）克制安排，超出时优先分页、轮换或拆场景。

## 不要做

- 不要把内容画进导航栏（`y < 88`）或字幕条（`y ≥ 1776` / `1296`）。
- 不要把主展示区内容越过 `y = 1200` / `880`，也不要让副展示区越过 `y = 1752` / `1272` 或压到人物区。
- 不要在人物区上方或右侧另塞文字块，也不要用单个图标或大数字填满副展示区。
- 字幕不要超过 `caption.width_px`（940px）对应的显示宽度，不要超过两行。
