# 布局：竖屏讲解模式（portrait-presenter）

这是带主持人的通用竖屏布局，不塞顶部导航栏和横屏右侧窄栏：上方保留全宽的页眉与主展示区，右下角坐着主持人讲解，底部是双行深色字幕条，主持人的笔记本和杯底自然压在字幕条上。

**所有区域的位置和尺寸都是固定的**。模板和组件只往区域里填内容，不移动、不缩放区域本身。内容放不下时，在区域内部缩小、滚动或分页。

画布有两种变体：**1080×1920（9:16）** 和 **1080×1440（3:4）**。本文档同时写两个变体的区域表；区域定义是一份画布一个 JSON：`portrait-presenter.json` 是 1080×1920，`portrait-3x4-presenter.json` 是 1080×1440。**JSON 里的数值必须和本文档的区域表一致**，改任何一个都要同步另一个。

竖屏讲解字幕允许两行，左对齐并停在人物左侧 30px 处。字幕规格（文字区宽度、字号、最大行数）由对应 JSON 的 `caption` 段决定。

     │  │   主展示区                       │  │
     │  │   70, 300 · 940 × 1170           │  │

| 背景 | 0, 0 | 1080×1920 | 主题背景（`--ground`），静态 | 视频的 `index.html`（`--ground`） |
| 页眉 | 70, 120 | 940×140 | 标题、日期或当前项目的一句话身份 | 场景 / 模板 |
| 主展示区 | 70, 300 | 940×1170 | 全部主要内容：纵向榜单、行卡、媒体 slab、图表 | 场景 / 模板 |

| 字幕条 | 0, 1776 | 1080×144 | 底部深色双行条（`--c-chrome`） | 组件 `caption-bar` |
| 字幕文字区 | 70, 1776 | 600×144 | 双行字幕（38px），左对齐、垂直居中；右边界停在人物左边缘前 30px | 组件 `caption-bar` |

     │                                        │

  210│  70, 90 · 940 × 120                    │

     │  │   主展示区                       │  │

| 区域 | 位置（左, 上） | 尺寸（宽×高） | 放什么 | 由谁填 |
|---|---|---|---|---|
| 背景 | 0, 0 | 1080×1440 | 主题背景（`--ground`），静态 | 视频的 `index.html`（`--ground`） |
| 页眉 | 70, 90 | 940×120 | 标题、日期或当前项目的一句话身份 | 场景 / 模板 |
| 主展示区 | 70, 250 | 940×740 | 全部主要内容 | 场景 / 模板 |
| 人物区 | 700, 1020 | 320×320 | 人物动作组件，笔记本底边压在底部字幕条上约 22px | 组件 `presenter` |
| 字幕条 | 0, 1296 | 1080×144 | 底部深色双行条（`--c-chrome`） | 组件 `caption-bar` |
| 字幕文字区 | 70, 1296 | 600×144 | 双行字幕（36px），左对齐、垂直居中；右边界停在人物左边缘前 30px | 组件 `caption-bar` |

各区域间距（两种竖屏画布通用）：
- 页眉底到主展示区 40px；
- 主展示区底到人物区上边界 30px（距人物头发顶部约 48px）；
- 字幕文字区右边缘到人物区左边缘 30px（670 → 700），人物区右边缘距画布右边界 60px（1020 → 1080）。

## 层级（z-index）

| 层 | z-index | 内容 |
|---|---|---|
| 背景 | — | `#ground`，在根节点最底层 |
| 场景 | 2 | 各视觉场景挂载点，按时间先后排在同一轨 |
| 转场 | 10 | 转场 `tile-wipe`（`transitions/tile-wipe/`），盖住场景，从底部字幕条和人物下面穿过 |
| 字幕 | 16 | 组件 `caption-bar` |
| 人物 | 20 | 组件 `presenter`，永远在最上面 |

## 挂载规则

- **常驻组件**（字幕条、人物）各挂一次，`data-start="0"`，时长等于整支视频，宿主 `data-width` / `data-height` 对应全片竖屏画布（`1080×1920` 或 `1080×1440`）；采用转场时，常驻转场挂一次，`data-start="0"`，时长等于整支视频。它们的数据用的是视频时间（秒）。
- 同片混用无主持人竖屏场景（`portrait` / `portrait-3x4`）时，不重挂组件，也不要给 `caption-bar` 传 `bar: "off"`：通过 `VIDEO.presenter.placements` 切换人物显隐与几何，通过 `VIDEO.captionSegments`（含 `caption_bar_rect`）自动切换底部字幕条显隐与双行文字区宽度。
- 采用方格转场 `tile-wipe` 时，按 [tile-wipe 文档](../transitions/tile-wipe/tile-wipe.md) 的参数公式传入本布局边界与笔记本起点：`9:16` 为 `{"originX": 860, "originY": 1748, "top": 0, "bottom": 1776}`，`3:4` 为 `{"originX": 860, "originY": 1268, "top": 0, "bottom": 1296}`；竖屏 1080px 宽度下默认省略转场预告卡片（只做纯方格过渡），避免横屏宽卡片横向越界。

## 人物和竖屏区域的配合

本布局的主展示区位于 320×320 人物区的正上方与左上方，没有右侧副展示区；视线方向（`glances`）与缩小舞台后的气泡缩放（`fxScale`）规则统一见 [presenter 组件文档](../components/presenter/presenter.md)。

## 竖屏摆法与信息密度

内容组织遵循 [portrait.md](portrait.md) 的「竖屏摆法与信息密度」：主展示区保持 940px 全宽上下堆叠与分时轮换，不塞左右窄栏；由于底部预留了人物与双行字幕条，纵向条目数应按主展示区高度（1170px / 740px）克制安排，超出时优先分页、轮换或拆场景。

## 不要做

- 不要把主展示区内容向下越过底边（9:16 的 `y = 1470`、3:4 的 `y = 990`），避免压住人物头顶或思考气泡。
- 不要在人物左侧（`y` 在主展示区底与字幕条顶之间的空白带）硬塞窄小文字块，把这块留给人物呼吸感与气泡提示。
- 字幕不要超过 `caption.width_px`（600px）对应的显示宽度，不要超过两行。
