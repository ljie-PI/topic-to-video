# 布局：舞台模式（stage）

这是一个通用横屏布局，不属于任何一类视频。**没有主持人**：整幅画面都是内容舞台，顶部保留导航栏，底部是贯穿全宽的字幕条。

**所有区域的位置和尺寸都是固定的**。模板和组件只往区域里填内容，不移动、不缩放区域本身。内容放不下时，在区域内部缩小或滚动。

机器可读的区域定义在同目录的 `stage.json`，数值与本文档区域表一一对应，改任何一个都要同步另一个。

画布 1920×1080，30 fps，左右边距 96px。

## 区域

| 区域 | 位置（左, 上） | 尺寸（宽×高） | 放什么 | 由谁填 |
|---|---|---|---|---|
| 背景 | 0, 0 | 1920×1080 | 主题背景（`--ground`），静态 | 视频的 `index.html`（`--ground`） |
| 导航栏 | 0, 0 | 1920×72 | 站点标志、页面路径、章节标签页；当前章节下有下划线，充当整片的进度条 | 组件 `nav-bar` |
| 页眉行 | 96, 100 | 1728×72 | 页面标题加日期，或当前项目的标题条 | 模板 |
| 主展示区 | 96, 196 | 1728×764 | 全部主要内容：大图、视频、榜单、图表、流程等 | 模板 |
| 字幕条 | 0, 1008 | 1920×72 | 深色条，和导航栏对称 | 组件 `caption-bar` |
| 字幕文字区 | 96, 1008 | 1728×72 | 单行字幕，左对齐，垂直居中 | 组件 `caption-bar` |

各区域间距：
- 页眉行底到主展示区 24px；
- 主展示区底到字幕条 48px；
- 主展示区左右边距各 96px。

## 层级（z-index）

| 层 | z-index | 内容 |
|---|---|---|
| 背景 | — | `#ground`，在根节点最底层 |
| 场景 | 2 | 模板里的场景（每个场景一个挂载点，按时间先后排在同一轨） |
| 转场 | 10 | 组件 `transitions/tile-wipe`，盖住场景，从导航栏和字幕条下面穿过 |
| 导航栏 | 15 | 组件 `nav-bar` |
| 字幕 | 16 | 组件 `caption-bar` |

## 挂载规则

与 `presenter.md` 相同：常驻组件（导航栏、字幕条、转场）各挂一次，`data-start="0"`，数据用视频秒；场景按时间顺序挂在同一轨，场景内时间从 0 算起；场景之间用 `tile-wipe` 衔接，切点后 0.55 秒（方格退去时）新内容再出现。

## 横屏摆法与信息密度

stage 就是横屏通用布局：信息形态自由，但密度有上限。

- 可用左右分栏、宽幅素材 + 外置信息区、下方 rail；流程可横向或纵向；list / grid 通常 2–4 项。
- 单素材为主时按可用宽高共同计算主体尺寸；极端比例素材用横向 reveal（视口沿长轴移动），不得缩成窄条或细线。
- 多素材对比：两个素材优先左右并排、统一高度；两个同屏不可读或三个以上时按时间逐个 / 分组比较，必要时拆场景，不默认三等分小宫格。
- 信息过密时优先轮换、分页、降级次要信息或拆场景；**不得**缩字号、缩素材或侵入字幕文字区。
- 文字放不下的处理顺序：换行（区域允许时）→ 区域内缩小 → 删减次要文字；不允许溢出区域或压在字幕条 / 导航栏上。

## 不要做

- 不要把主展示区内容画出区域外，尤其不要压到字幕条上。
- 字幕不要超过 1728px 对应的显示宽度，不要折成两行（`stage.json` 的 `caption.max_lines` 是 1）。
- 不要在没有主持人的画面上再叠加人物组件；需要人物解说时用 `presenter` 布局。
