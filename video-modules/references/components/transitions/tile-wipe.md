# 组件：transitions/tile-wipe（方格转场）

**用在两个场景交接的地方。**

1. 切点前约 0.45 秒，方格从一个点（默认是人物的笔记本）向外一圈圈亮起，越靠近起点越密。
2. 到切点时刻，方格完全盖住画面。旧场景在方格下面结束，新场景在方格下面开始，所以切换本身看不见。
3. 盖满后，画面中间可以亮出一张卡片，预告下一段，比如“#1 某某项目”。
4. 切点后约 0.55 秒，方格收回起点，露出新场景。

方格从顶部导航栏和底部字幕条的下面穿过，这两条一直可见。

**组件本身没有任何具体内容**：
- 切点和卡片文字在拼视频时传入。
- 方格颜色读主题的 `--c-tile0`–`--c-tile4`，卡片配色和字体也都读主题变量。

这一类视频想让方格带特定含义时，由模板覆盖方格颜色。比如 GitHub 模板把方格换成贡献图的绿色。

## 文件

- `assets/components/transitions/tile-wipe/tile-wipe.html`

## 依赖（来自设计主题，视频的 `index.html` 必须提供）

| 变量 | 用在哪里 |
|---|---|
| `--c-tile0` … `--c-tile4` | 方格五档颜色 |
| `--c-card` | 方格缝隙后面的底板、卡片底 |
| `--c-border` | 卡片边框和分隔线 |
| `--c-ink` / `--c-ink2` | 卡片大标签 / 附加信息 |
| `--c-focus` | 卡片标题 |
| `--c-positive` | 附加信息里的强调数字 |
| `--font-sans` | 字体 |

## 安装

1. 把 `assets/components/transitions/tile-wipe/tile-wipe.html` 复制到视频工程的 `compositions/tile-wipe.html`。
2. 在根节点加挂载点：
   - `data-composition-id="tile-wipe"`，`data-composition-src="compositions/tile-wipe.html"`；
   - `data-start="0"`，时长为整片；
   - `style="z-index: 10"`：在场景之上，在界面条和人物之下。

## 挂载参数

| 参数 | 默认 | 说明 |
|---|---|---|
| `originX`, `originY` | 1504, 968 | 方格扩散的起点，单位 px。默认是讲解模式布局里人物笔记本的位置；人物移动了要跟着改（人物舞台左上角加上 0.5 倍和 0.775 倍边长） |
| `top`, `bottom` | 72, 1080 | 方格铺设的上下范围，单位 px。默认从导航栏下沿开始 |
| `cardX`, `cardY` | 240, 410 | 卡片左上角，单位 px |
| `data` | `"cuts"` | 从 `window.VIDEO` 的哪个键读切点 |

## 数据（`window.VIDEO.cuts`）

```js
cuts: [
  { at: 20.7,                       // 切点，视频秒；等于下一个场景的 data-start
    label: "#1",                    // 卡片左侧的大字；不填就不出卡片，只有方格
    title: "storytold / ",          // 标题（常规字重）
    emphasis: "artcraft",           // 接在标题后面的加粗部分
    meta: [                         // 标题下的一行附加信息，每项可带：
      { dot: "#dea584", text: "Rust" },          //   dot：前面的小色点
      { strong: "+20,267", text: "star 本周" },  //   strong：强调数字（指标色）
    ] },
]
```

## 时间线

| 时间 | 发生什么 |
|---|---|
| `at - 0.45` | 方格开始点亮 |
| `at` | 完全盖住画面 |
| `at - 0.03` 到 `at + 0.45` | 卡片显示 |
| `at + 0.55` | 方格开始收回起点，约 0.4 秒收完 |

## 配合其他模块

- 新场景开头约 0.55 秒被方格盖着，所以场景里第一个元素最好在 0.55 秒之后出现。
- 导航栏的下划线在 `at - 0.1` 秒开始移动，正好在盖住期间完成，`tabs[].at` 用同一个时间就行。
- 人物在切点前约 0.85 秒开始打字（`jay.typing`），看起来就像方格是从他的笔记本里冒出来的。
